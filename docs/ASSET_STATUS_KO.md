# 실제 제공 리소스 점검 및 적용 명세
점검일: 2026-10-22. 이 문서는 파일 실사 결과이며, 게임에서 검증을 마쳤다는 주장이 아니다.

## 제공됨
`public/assets/ganggamchan_v2/`에 기존 v2 ZIP의 파일 100개를 원본 그대로 포함했다.
캐릭터 개별 PNG **49개**, 이펙트 PNG **23개**, 총 **72프레임**이다.
모든 개별 프레임은 128×128 RGBA. 전체 아틀라스는 1024×1152이며 JSON frame 이름을 사용한다.
지면 기준 y=114, origin=(0.5, 0.890625), 기본 방향 오른쪽. 왼쪽은 flipX로 처리한다.
원본의 `metadata/frames.json`과 `metadata/validation.json`을 반드시 읽는다.

## 파일을 불러오는 기준
런타임에는 `runtime_assets.json`의 atlas PNG와 JSON 한 쌍을 불러오면 모든 72프레임을 참조할 수 있다.
개별 PNG와 sheets는 편집·검증용이며 같은 그림을 중복 로딩할 필요가 없다.
`frames`의 key를 그대로 사용하고, 전체 이미지를 격자로 다시 임의 분할하지 않는다.
`previews`, `review`는 런타임 텍스처가 아니다. 원본 안내 이미지나 배경 체크무늬가 들어간 미리보기를 쓰지 않는다.
Phaser `load.atlas` 후 `textures.exists`, `textures.get(key).has(frameName)`로 프레임 존재를 검사한다.

## 알려진 결손과 처리
- `heavy`에는 준비 자세 2장만 있다. 완성 강공격으로 표시하지 않는다. 개발용 임시 연결은 `animation_bindings.json`에 명시했다.
- 차징 3단계·지휘 동작·공중 공격·착지의 독립 완성 시트는 없다. 해당 기능 자체를 빼지 않고 기존 포즈+효과로 임시 표현한다.
- 일부 검기·대쉬 잔상은 본체에 합쳐져 있다. 중복 이펙트를 얹어 실루엣을 가리지 않는다.
- 공격3 일부 프레임에 원본 가장자리 경고가 있다. 원본에서 이미 빠진 픽셀을 자동 복원했다고 주장하지 않는다.
- 점프 프레임은 원본 내 높이 차이를 가진다. 물리 바디 발 위치와 그림의 위치를 분리한다. 프레임별 시각 오프셋을 검수하며 물리 좌표를 그림에 맞춰 바꾸지 않는다.
- 기본 히트박스는 128×128 전체가 아니다. 투명 여백/검기/머리 장식은 몸통 피격 판정에 넣지 않는다.

## 아직 없는 최종 리소스
일반 적 5종, 보스 3종, 지원 창병·방패병, 맵 3종, 군량 아이콘, 보상/UI 스킨, 최종 엔딩 그림, 음악/효과음 파일은 이 패키지에 없다.
Claude Code는 이들이 이미 존재한다고 가정한 경로를 코드에 넣어 404를 발생시키면 안 된다.
외부 유료 에셋 구매나 서비스 가입을 임의로 수행하지 않는다.

## 개발을 멈추지 않는 대체 정책
코드 단계에서만 `generated_*` 이름의 절차적 픽셀 텍스처와 Web Audio 임시 효과음을 만들 수 있다.
적은 무기·실루엣·적갈색으로 구분하고, 아군은 남색으로 구분한다. 보스는 크기·무장·실루엣을 따로 준다.
이 대체물은 **최종 픽셀아트 납품 완료로 계산하지 않는다**. 완성도 표에 `temporary`로 표시한다.
개발용 무음을 정식 국악+액션 BGM이라고 보고하지 않는다.
리소스 교체는 manifest 경로와 animation binding만 바꾸도록 설계하고 게임 수치를 바꾸지 않는다.
사용자가 원한 최종 목표는 모든 캐릭터/애니메이션을 포함한 3라운드 완성이다. 임시 자료는 구현 순서상의 수단이지 범위 축소 승인이 아니다.

## 아트 최종 검수
모든 자세에서 머리·발·검끝 잘림, 위쪽 타 프레임 잔여물, 크기 변화, 발 미끄러짐을 확인한다.
회색·흰색·검정 배경에서 alpha halo를 검사한다. 1배/2배/3배 및 좌우 반전 모두 검수한다.
애니메이션은 미리보기뿐 아니라 실제 Phaser 화면에서 확인하고 결과를 문서에 기록한다.
