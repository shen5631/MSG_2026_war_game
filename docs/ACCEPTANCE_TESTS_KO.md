# 인수 테스트와 회귀 점검표

총 **111개**의 게임 검증 항목. 아래는 실행 예정 시험이며, 이 전달 패키지에서 실제 게임 시험이 완료됐다는 의미가 아니다.

`reference/combat-math.test.mjs`의 순수 수식 예제 테스트는 별도이며 게임의 브라우저/패드 검증을 대체하지 않는다.

## 실행 원칙
각 케이스에 실제 실행 날짜·OS·브라우저·컨트롤러·결과·문제 링크를 기록한다. 자동화 가능한 것은 Vitest/Playwright로 구현한다. 실기 항목은 실제 연결된 패드와 브라우저에서 실행한다.

시간 경계는 원시 timestamp를 주입한 단위 시험과 실제 입력 시험을 나누어 검사한다. 브라우저 렌더 간격으로 인한 샘플 지연을 테스트 통과 수치로 숨기지 않는다.

## 판정
기능 완료: 핵심 수치·상태·경계·전체 흐름이 통과. 아트 완료: 모든 결손/임시 자료 교체와 실사용 검수. 배포 가능: 빌드/정상 완주/브라우저·패드/사용권 검토 완료. 이 세 가지를 따로 보고한다.
