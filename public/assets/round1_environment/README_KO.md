# 강감찬 1라운드 지형·발판·소품 분리본

## 들어 있는 것

두 원본 아틀라스에서 **67개의 개별 투명 PNG**를 추출했습니다.
- 지형 36개: 흙길 표면 11 + 절벽 전면 7 + 가장자리 9 + 높은 블록 6 + 계단 3.
- 목재 발판 15개: 완성 발판 6 + 발판 조각 9.
- 소품 16개: 방어 구조물 4 + 상자/통 3 + 장식 2 + 잔해 7.
- 따라서 지형 36 + 발판 15 + 소품 16 = 67개입니다.

## 폴더

```text
round1_environment_split/
  terrain/
    ground_surfaces/  # 11개: 흙길 윗면
    cliff_faces/      # 7개: 절벽 전면
    cliff_edges/      # 9개: 가장자리/코너
    raised_blocks/    # 6개: 높이가 있는 블록
    steps/            # 3개: 계단형 지형
  platforms/
    wood_full/        # 6개: 긴 목재 발판
    wood_parts/       # 9개: 짧은 목재 발판/연결 조각
  props/
    defenses/         # 4개: 목책·방벽·엄폐물·울타리
    containers/       # 3개: 나무 상자·통·보급 상자
    decor/            # 2개: 화로·깃발+돌담
    wreckage/         # 7개: 수레·바위·돌담·붉은 깃발 잔해
  atlas/              # 선택적으로 사용할 67개 통합 PNG+JSON
  originals/          # 수정하지 않은 원본 2장
  previews/           # 목록 PNG와 파일별 미리보기 HTML
  manifest.json       # 파일 경로·크기·원본 좌표·기준점
  validation.json     # PNG/여백/아틀라스 일치 검사
```

## 크기와 투명도

- 원본 그림을 **동일한 크기로 등분하지 않았습니다.** 각 물체의 실제 윤곽으로 분리했습니다.
- 그림 자체는 원본 해상도를 유지했고 크기 변경/회전/재생성은 하지 않았습니다.
- 각 PNG에는 4px 투명 여백을 추가했습니다. 이미지마다 폭과 높이는 다릅니다.
- 원본의 거의 보이지 않는 낮은 알파 배경 노이즈를 제외했습니다. 본체의 색과 알파값은 유지했습니다.
- 체크무늬는 `previews/`에서만 보이는 투명도 표시입니다. 실제 에셋에 체크무늬나 바탕색을 넣지 않았습니다.
- 640×360 게임에 넣을 때는 원본 크기를 그대로 월드 크기로 사용하지 말고 크기를 조절하세요. 공통 배율 0.25는 초기 배치 참고값일 뿐, 확정한 게임 규칙이 아닙니다.
- 실제 표시 크기는 강감찬 캐릭터, 점프 높이, 충돌 박스와 맞춰 조정하세요.

## 개별 PNG와 통합 아틀라스

개별 파일은 `terrain/`, `platforms/`, `props/`를 사용하세요.
통합본은 `atlas/round1_environment.png`와 `atlas/round1_environment.json`을 한 쌍으로 사용합니다.
각 프레임 이름은 `manifest.json`의 `key`와 같습니다. 균등한 크기의 스프라이트 시트가 아니므로 고정 칸 크기로 다시 자르지 마세요.
`manifest.json`의 `anchor_px`는 아래쪽 가시 영역을 기준으로 한 배치 참고점이며, 충돌 박스가 아닙니다.

## 반드시 구분할 점

1. **깃발+돌담**: `blue_banner_stone_ruin.png`는 원본에서 깃대가 돌담과 연결되어 있어 하나로 보존했습니다. 독립적인 깃발/돌담 두 장으로 무리하게 자르지 않았습니다.
2. **정지 이미지**: 화로와 깃발을 포함한 모든 파일은 정지 이미지입니다. 애니메이션 프레임을 추가 제작한 것이 아닙니다.
3. **타일 이음새**: 원본의 지형은 크기와 가장자리 모양이 다릅니다. 이음새 없는 32px/64px 반복 타일로 검증한 결과물이 아닙니다. 장식 이미지나 개별 지형 조각으로 먼저 배치하세요.
4. **충돌 및 파괴**: 발판의 통과/착지 판정, 상자 파괴, 화살 차단, 불꽃 피해는 포함되어 있지 않습니다. 기존 기획의 코드와 별도 연결해야 합니다. 소품 이름만으로 게임 기능이 확정되지는 않습니다.
5. **검증 범위**: PNG 모드·투명 여백·각 본체 픽셀 보존·통합 아틀라스의 픽셀 일치 여부를 검사했습니다. 실제 Phaser 실행이나 전투/맵 충돌 검증은 하지 않았습니다.
6. 이 ZIP은 지형·발판·소품 2장의 분할본입니다. 이전에 만든 성곽 마을 전체 배경 일러스트는 이 묶음에 포함하지 않았습니다.

## Claude Code에 전달할 문장

> 이 폴더의 README_KO.md와 manifest.json을 읽고 기존 1라운드에 지형·발판·소품 이미지를 연결해 줘. 개별 PNG 또는 제공된 아틀라스 PNG+JSON을 사용하고, 원본 아틀라스를 동일 크기로 다시 등분하지 마. 투명 여백과 물체별 크기를 고려해서 캐릭터 크기에 맞춰 배치해. 충돌은 기존 기획에 따라 별도로 설정하고, 소품을 무조건 피해 지형으로 만들지 마. 깃발과 돌담 결합 소품은 분리하려 하지 말고 하나로 사용해. 반복 타일 이음새는 아직 검증되지 않았으므로 화면에서 확인해.
