# 강감찬 분리 리소스 v2 — 기존 이미지의 실제 분할본

이 패키지는 새 그림을 생성한 것이 아니라 마지막으로 제공된 1536×1024 시트를 실제로 분할·가공한 것입니다.
최종 개발 기획서가 아니며 기존 게임 규칙은 변경하지 않았습니다.

## 포함 파일
- frames/character/: 대기·걷기·달리기·점프·공격·패링·대쉬·피격·사망의 개별 투명 PNG.
- frames/effects/: 개별 효과 PNG. 서로 다른 효과가 섞여 있으므로 한 번에 전부 이어 재생하지 마세요.
- sheets/: 동작별 1행 스프라이트 시트. 모든 칸은 128×128, margin=0, spacing=0.
- ganggamchan_atlas.png + ganggamchan_atlas.json: 동일 이름으로 짝지어 사용하는 전체 이미지 아틀라스.
- metadata/frames.json: 이름, 경로, 원본 잘라낸 좌표, 앵커, 주의 사항.
- metadata/frame_index.csv: 전체 프레임 순서표.
- previews/preview.html: 인터넷 연결 없이 열 수 있는 이미지 동작 확인 도구. 실제 Phaser 게임 테스트가 아닙니다.
- review/: 두 칸에 걸쳐 겹친 강공격 원본. 게임용 폴더에 억지로 끼워 넣지 않았습니다.

## 적용 규격
- 개별 PNG는 모두 128×128 RGBA, 바깥 배경은 alpha=0입니다.
- 캐릭터는 원본을 일괄 0.75배 nearest-neighbor로 축소했습니다. 프레임마다 다른 비율로 늘리지 않았습니다.
- 캐릭터 기준점: x=64, 지면 기준 y=114 (originX=0.5, originY=0.890625).
- 점프 프레임은 높이 변화를 보존했습니다. 각 포즈의 발을 같은 바닥에 강제 접지하지 않았습니다.
- 기본 방향은 오른쪽이며, 좌우 반전은 게임에서 처리합니다.
- 시트에는 제목, 번호, 칸 테두리를 넣지 않았습니다. previews의 설명 그림은 게임 텍스처가 아닙니다.
- 원본의 엷은 반투명 배경 잔여물을 정리했습니다. 본체/무기 모양을 새로 그린 것은 아닙니다.
- 옆 칸으로 넘어간 검 끝은 원래 공격 프레임에 포함했습니다. 검을 가로지르던 1~2픽셀 구분선과 인접 번짐은 주변 픽셀로 보간했습니다.

## 반드시 알아둘 한계
1. HEAVY 원본의 3·4번은 하나의 큰 그림이 두 칸에 걸쳐 있습니다. 잘못 자르면 검과 캐릭터가 잘립니다.
   그래서 heavy에는 깨끗하게 나눌 수 있는 2개 준비 포즈만 포함했습니다. 최종 타격 이미지는 review/에 보존했습니다.
   완성된 강공격 애니메이션이라고 간주하지 마세요.
2. 일부 검기·패링·대쉬 잔상은 캐릭터에 이미 합쳐 그려져 있습니다. 별도 effects 폴더가 있다고 모든 본체에서 효과가 분리된 것은 아닙니다.
3. 원본에 닿은 검 끝/이펙트의 누락 픽셀을 새로 복원하지 않았습니다. 해당 프레임은 frames.json warnings에 표시했습니다.
4. 원본에서 캐릭터 비율·복식·몸통 위치가 약간씩 바뀝니다. 동일 캔버스/지면 정렬은 했지만, 새로 작화한 동일 모델 애니메이션은 아닙니다.
5. attack_1/2/3, heavy, skill 등은 원본 표제의 구분입니다. 확정된 게임의 약공격·강공격·차징·지휘와 연결하는 것은 게임 로직에서 정해야 합니다.
6. 지휘 명령·차징 3단계·공중 공격·착지 등 게임 설계의 모든 동작이 이 원본에 독립적으로 있지는 않습니다.
7. previewFps는 그림 미리보기용입니다. 패링 0.2초, 차징 0.5/1.0/1.5초 등 확정한 게임 판정 시간을 변경하면 안 됩니다.
8. 직접 분할·파일 크기·투명 테두리는 검사했지만 Phaser 엔진에서 이동/충돌/전투까지 검증한 패키지는 아닙니다.

캐릭터 origin은 0.5, 0.890625로 사용해. heavy는 준비 포즈만 있으므로 완성된 공격이라고 가정하지 마.
그림 애니메이션과 게임의 충돌·공격 판정을 분리해. 기존 확정 게임 수치와 규칙은 바꾸지 말고,
먼저 대기/걷기/달리기/점프의 크기와 바닥 위치를 확인해. 이펙트 시트는 서로 다른 효과의 모음이므로
모든 칸을 하나의 루프로 자동 연결하지 마."
