# 거란군 적 방패병 V2 — 이미지·프로젝트 연결 패키지

이 캐릭터는 **일반 적 shieldman**입니다. 고려군 아군 방패병 스킬이나 정예 창병장 보스가 아닙니다.

## 먼저 확인
1. `START_PREVIEW.html`을 열어 실제 프레임, 좌우 반전, 공격·방어·피격을 확인합니다.
2. 로컬 HTML 실행이 브라우저 정책으로 차단되면 이 폴더에서 `npm run demo`를 실행합니다. Node.js가 있으면 이 명령은 별도 패키지 설치가 필요 없습니다.
3. 기존 게임에 추가할 때 `CLAUDE_IMPORT.md`와 `docs/INTEGRATION_KO.md`를 읽습니다.

## 실제 이미지 목록
| 동작 | PNG 파일 수 | 의미 |
|---|---:|---|
| idle | 4 | 대기 |
| walk | 6 | 이동 |
| guard | 4 | 정면 방어·막기 반응 |
| attack | 6 | 준비 → 일반 방패 공격 → 복귀 |
| guard_break | 4 | 가드 파괴 후 경직 |
| hurt | 4 | 일반 HP 피격. guard_break 자세를 별도 파일명으로 재사용 |
| death | 5 | 무너짐 → 최종 쓰러짐 |

**게임용 PNG 33개, 서로 다른 그림 29개**입니다. 피격 슬롯을 독립시켰다고 새로운 그림 4장을 그린 것은 아닙니다. 사망은 실제 5장이며 없는 6번째 포즈를 추가했다고 표기하지 않았습니다.

## 이미지 수정 범위
- 이전에 분리해 둔 원본에서 색 정보를 다시 가져와 명암·윤곽을 조정했습니다.
- V1의 80색보다 많은 공통 256색 팔레트를 사용하고 디더링 없이 저장했습니다.
- 기존 디자인·동작의 정리본이며 신규 고해상도 작화나 새로운 29개 포즈를 다시 그린 결과는 아닙니다.
- 글자, UI, 설명 패널, 폴더 그림, 체크무늬는 실제 스프라이트에 없습니다.
- 원본 해상도 분리본은 `source/masters`, 확대 편집용 384×384는 `source/detail_2x`입니다. 확대본을 새로운 디테일이 생성된 원본으로 취급하지 않습니다.

## 표시 규격
- 게임용 프레임: **192×192 RGBA PNG**
- 발 기준점: **(96,160)**
- origin: **(0.5, 160/192)**
- 기본 scale: **1**, 기본 방향: 오른쪽, 좌향: `flipX`
- 서 있는 대기/이동 몸체: 약 97~98px. 투명 캔버스의 192px 전체가 몸체 높이가 아닙니다.
- 33개 파일의 비어 있는 가장자리 여백 최소 **32px**.
- 프레임마다 `setDisplaySize` 또는 자동 crop을 반복하지 않습니다. 투명 캔버스 전체를 물리 충돌 영역으로 사용하지 않습니다.
- 원본은 전부 보존하며 잘려서 빠진 새로운 해부학적 형태를 복원했다고 주장하지 않습니다.

## 연결 코드
- `src/enemy/core.ts`: 상태별 표시 프레임, 공격 유효시간, 선택적 정면 방어 판정.
- `PhaserShieldEnemyView.ts`: 기존 AI의 위치·상태·상태시간을 받아 표시만 변경합니다. **피해를 적용하지 않습니다.**
- `ShieldEnemyController.ts`: AI가 없는 경우 참고할 단일 적 동작 제어기. 평지 검사와 전투 규칙 확인용입니다. 지형 충돌·다수 적 공격 슬롯·웨이브·드롭·플레이어 보호막은 호스트 게임이 처리합니다.
- 기존 AI가 이미 있다면 **View만** 사용하고 Controller를 동시에 붙이지 않습니다.
- 입력 스냅샷은 `x`, `feetY`, `facing`, `state`, `stateElapsedMs`입니다. 일시정지는 이 시뮬레이션 시간과 게임 시간을 같이 멈춥니다.

## 확정 설정과 구현 기본값
기존 기획서 §10.1~10.3을 따릅니다. HP80은 확정값입니다. 피해10, 속도42px/s, 사거리62px, 예고650ms/유효120ms/회복900ms, 가드 경직800ms는 기획서의 구현 기본값입니다.
정면 약공격·공중 약공격·대쉬를 막으면 피해0. 강공격·마무리·차징은 정상 피해와 가드 경직. 뒤쪽 및 아군 창병 지원은 방어를 관통합니다. 적의 공격 중에는 방어가 해제됩니다. 그림의 방패 이펙트가 독립 피해를 주지는 않습니다.

## 실행과 검증
- `npm run demo`: Node.js 내장 서버로 독립 Canvas 검사 화면 열기
- `npm test`: 포함된 빌드 JavaScript에 대한 Node 단위 테스트
- `npm run typecheck`, `npm run build`: TypeScript가 설치된 환경에서 `src/` 검사·빌드
- `python tools/validate_images.py`: Pillow 설치 환경에서 이미지/아틀라스 검사
- 실제 결과는 `validation/VALIDATION_KO.md`에 기록했습니다.

**이 패키지에서 확인한 독립 Canvas 검사와 실제 Phaser 엔진 실행은 다릅니다.** 실제 Phaser 및 사용자 기존 프로젝트 통합은 여기서 실행하지 않았습니다. Phaser Scene 예제는 호스트 프로젝트에 옮겨 검사해야 합니다. 게임패드·전체 라운드·60FPS 보증도 해당하지 않습니다.
