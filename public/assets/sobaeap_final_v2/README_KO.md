# 소배압 최종 보스 V2 — 분리된 픽셀아트·Phaser 렌더링 패키지

이전 소배압 V1의 잘못 잘린 프레임을 대체하는 **게임용 표시 리소스**입니다.

## 핵심 정보
- 최종 보스: **소배압**, 3라운드
- **최대 HP 700 / 2페이즈 HP 350 이하** (기존 확정 기획 유지)
- 기본 방향: 오른쪽 / 왼쪽 `flipX`
- 게임용 개별 프레임: **448×256 RGBA 투명 PNG**. 실물 본체는 이보다 작음
- 발 기준점: **(224, 220)**, Phaser `origin=(0.5,0.859375)`, 우선 `scale=1`
- 원본 이미지 간 붙은 포즈를 강제로 쪼개면 창과 망토가 잘리거나 옆 캐릭터가 섞입니다.
  그런 포즈는 사용하지 않고 온전한 포즈를 재배열했습니다. `manifest.json`의 `source_pose`와 `docs/PROVENANCE_KO.md`에 기록돼 있습니다.
- **동작별 spaced_strips에는 프레임 사이 투명 40px 여백**이 들어 있습니다. 실제 개별 PNG에도 충분한 여백을 둠

## 실제 프로젝트에 적용
1. `public/assets/sobaeap_final_v2`를 프로젝트의 `public/assets/`로 복사합니다.
2. `src/boss/PhaserSobaeapVisual.ts`에서 `preloadSobaeapAssets`는 Scene.preload에서, `createSobaeapAnimations`는 Scene.create에서 부릅니다.
3. **기존 보스 AI가 이미 있다면** `SobaeapVisual`만 붙여 상태·시간을 전달합니다. 별도 AI를 중복 실행하지 않습니다.
4. `setDisplaySize`, crop, 고정 128px 텍스처 자르기 등을 사용하지 마세요. 실제 충돌판정은 투명 448×256 영역이 아니라 별도 몸체/무기 히트박스를 씁니다.
5. `sync({x,y,facing,action,elapsedMs})`는 기존 AI의 시간·상태로 프레임을 결정합니다. 연속 타격 피해나 보스 패턴은 표시 컴포넌트가 담당하지 않습니다.
6. 애니메이션 구성 중 안전하지 않은 원본 프레임은 재사용 포즈로 대체하였으므로, `attack`·`combo`에는 반복 그림이 있습니다. 테스트 후 필요할 경우 원본에서 독립적으로 다시 그린 포즈로 교체하십시오.

## 설명 / 제한
`START_PREVIEW.html`은 실제 분리된 개별 PNG를 재생하는 독립 HTML 검사용 화면입니다. Chrome에서 압축을 푼 폴더 안에서 열면 됩니다. 게임의 전투 AI/스킬 시스템을 실행하는 화면은 아닙니다.
이 패키지는 소배압 그래픽 연동용이며, 기존 React+Phaser 프로젝트를 입력받아 통합 빌드한 결과는 아닙니다. 일부 원본 스프라이트는 처음 생성 시점부터 다른 포즈와 겹쳐 있는 부분이 있어 **모든 그림이 새로 복원된 것은 아닙니다.**
