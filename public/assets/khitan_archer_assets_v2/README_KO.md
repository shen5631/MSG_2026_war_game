# 거란군 궁병 이미지 폴더 · v2 수정본

## 내용
- 캐릭터 25장: idle 4 / walk 6 / attack 6 / hurt 3 / death 6.
- 화살 2장: 발사체 모양 변형. 연속 애니메이션으로 재생할 필요 없음.
- 캐릭터: 128×128 투명 RGBA PNG. 오른쪽 방향, 왼쪽은 반전.
- 화살: 64×32 투명 RGBA PNG.
- 모든 캐릭터 바닥 기준 y=122, 배치 기준점 x=64. 권장 origin=(0.5,0.953125).
- 동작별 PNG, 스트립, 전체 캐릭터 atlas PNG/JSON, manifest 포함.

## 이전 버전에서 수정한 부분
1. 사망 상단 포즈의 발이 다음 행에 들어가던 문제: 균등 분할 대신 원본 윤곽 범위로 다시 추출.
2. 사망 하단 포즈 위쪽에 남던 다른 칸의 발/잔여 조각 제거.
3. 동작별 원본 배율 차이를 보정하여 대기·이동·공격·피격의 대략적인 신장 통일.
4. attack_06에 그려진 분리된 날아가는 화살 제거. 실제 화살은 projectiles에서 별도 사용.
5. 화살 파일을 올바른 원본에서 추출. 화살 2장을 한 공격에서 동시에 발사하지 않음.

## Claude Code 연결
프로젝트 public/assets/ 아래에 이 폴더를 넣고 CLAUDE_IMPORT.md를 참고하세요.
전체 캐릭터 atlas는 atlas/khitan_archer_all_atlas.png 및 같은 이름 JSON입니다.
동작별 strip과 개별 PNG는 편집/대체용이며 전체 atlas와 동시에 중복 로딩할 필요 없습니다.
원본을 다시 등분하지 말고 manifest.json의 파일명/프레임을 그대로 사용하세요.

미리보기에서 발 잘림 및 타 프레임 조각 유입을 확인합니다.

이 패키지는 이미지/메타데이터이며 기존 게임 규칙을 변경하지 않습니다.
